Agent-LDP-Kangnam

Agent dựng landing page cho hệ sinh thái Kangnam, xuất phát từ hành vi khách hàng. Kiêm ba vai: 60% CRO · 25% conversion copywriter · 15% UX/UI mobile-first. Cài xong trong ~15 phút.

v1.2 8 file tri thức 8 lệnh Claude · ChatGPT · Gemini

Đo bằng bốn chỉ số: CVR · tỉ lệ lead kết nối · booking · show-up. Không tối ưu lượt xem, time-on-page hay độ “đẹp”.

Bước 1

Cài đặt theo nền tảng

Agent là prompt + tri thức, không phải phần mềm. Cài = tạo project trên nền tảng AI, dán bộ não vào ô instructions, nạp 8 file tri thức.

Claude Project — khuyến nghị

Ô instructions không giới hạn 8.000 ký tự nên dùng được bộ não đầy đủ.

  1. Projects → Create project → đặt tên Agent-LDP-Kangnam.
  2. Set project instructions → dán Thẻ A · Bộ não.
  3. Add content → upload đủ 8 file trong knowledge/.
  4. Upload thêm template/lp-skeleton.html để lệnh /prototype dựng đúng khung ngay lần đầu.
  5. Mở chat mới → gõ /brief.

ChatGPT Custom GPT

Ô Instructions giới hạn 8.000 ký tự → bắt buộc dùng bản ngắn.

  1. Explore GPTs → Create → tab Configure.
  2. Name: Agent-LDP-Kangnam.
  3. Instructions → dán Thẻ B · Bản ngắn (@@LEN_B@@ ký tự).
  4. Knowledge → upload đủ 8 file + lp-skeleton.html.
  5. Bật Web Browsing nếu muốn agent tự lấy giá động từ /bang-gia/.
Bản ngắn đã cắt ma trận kênh, bảng thứ tự trust và nhiều luật chi tiết — nó trông vào tri thức để bù. Không nạp tri thức thì bản ngắn sẽ bắt đầu đoán, và đoán sai ở chỗ pháp lý.

Gemini Gems

  1. Gems → New Gem.
  2. Ô Chỉ dẫn → dán Thẻ A · Bộ não.
  3. Upload đủ 8 file tri thức vào phần tệp của Gem.
  4. Mở chat → gõ /brief.

Dùng Claude Code / VS Code: mở thư mục Agent-LDP-Kangnam/ rồi nói “Đọc SYSTEM-PROMPT.md và toàn bộ knowledge/, sau đó hành xử đúng như Agent-LDP-Kangnam”.
